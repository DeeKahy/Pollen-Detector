# Iterations

A log of every version we build, with photos. This is the place for pictures of the
device, example camera images, test results and what went wrong.

## How to add one

1. Make a folder named `vN-short-name`, for example `v1-first-tape-deck`.
2. Copy [_template.md](_template.md) into it as `README.md` and fill it in.
3. Put photos next to it. Keep them small (resize to about 1500 px wide, JPEG).
4. Add a few example camera pictures. Full-size raw images are too big for git.
   Put those somewhere else (a shared drive, or Zenodo later) and link to them.
