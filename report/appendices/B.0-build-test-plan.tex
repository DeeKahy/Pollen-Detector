\textbf{Idea only. To be discussed with Florian.}

\section*{Before the test}
\begin{itemize}
  \item Prepare one kit per participant: printed parts, electronics, SD card, tools, and a
  printed copy of the build guide.
  \item Explain that we test the guide, not the participant. Ask for consent to take notes and
  photos of the hands and the device (no faces).
  \item Explain thinking aloud: say what you do, what you expect, and what confuses you.
\end{itemize}

\section*{Tasks}
Follow the build guide from start to end. If time is short, use only some of the tasks.
\begin{enumerate}
  \item Put together the printed enclosure and the tape transport.
  \item Mount the motor, fan, light and camera.
  \item Wire everything to the Raspberry Pi using the wiring diagram.
  \item Prepare the SD card and start the software.
  \item Load a piece of tape and take the first picture.
\end{enumerate}

\section*{Observer notes, per task}
\begin{itemize}
  \item Start and end time.
  \item Mistakes, and whether the participant found and fixed them.
  \item Each time help was needed: what the problem was and what we said.
  \item Quotes from thinking aloud that show confusion.
\end{itemize}

\section*{Short interview afterwards}
\begin{enumerate}
  \item Which step was hardest, and why?
  \item Was anything in the guide unclear or missing?
  \item Would you have finished without help?
  \item Would you build one at home? What would make it easier?
\end{enumerate}

\section*{After each participant}
Fix the guide where people got stuck, then test the new version with the next participant.
Write down what changed so the report can show how the guide improved.
\end{planned}
