# Pollen recognition

Not started yet.

## Plan

1. Collect pictures from the device, including pictures of known pollen put on the tape by hand.
2. Find the particles in each picture (simple blob detection first).
3. Sort them: pollen or not pollen (dust, bubbles, tape marks).
4. Sort the pollen by type: birch, grass, mugwort, alder, hazel, elm, ragweed.
5. Count per type and turn it into grains per m³ using the fan's airflow.

Biologists will help label the pictures.

## Data

Keep large image sets out of git. Put them on a shared drive or Zenodo and link to them here.

Public datasets that may help are listed in [../docs/references.md](../docs/references.md).
